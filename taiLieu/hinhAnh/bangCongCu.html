BẢNG TỔNG HỢP CÔNG CỤ & CÔNG NGHỆ SỬ DỤNG TRONG DỰ ÁN

Hệ thống Quản lý Nhà hàng & Gọi món QR tại bàn (QUANMOC.COM) — Nhóm 1 (Lớp N07)

18 Công cụ & Công nghệ
5 Thành viên đội ngũ
4 Sprints Quy trình Agile/Scrum
140 User Stories chi tiết
100% Offline QR Vector SVG thuần Client
STT Phân nhóm Tên công cụ / Công nghệ Mục đích sử dụng trong dự án Thành viên phụ trách Ưu điểm nổi bật & Lý do lựa chọn
1 Frontend
HTML5 & CSS3 hiện đại
 Xây dựng layout giao diện SPA, responsive đa thiết bị (Mobile-first cho khách gọi món, Desktop cho Quản lý / Thu ngân). Quân Phong Giao diện tải tức thì, nhẹ, tuân thủ chuẩn W3C, không phát sinh chi phí đóng gói thư viện (bundle).
2 Frontend
Vanilla JavaScript (ES6+)
 Xử lý toàn bộ logic động: E-Menu, giỏ hàng, modal, bộ lọc tìm kiếm, điều hướng SPA không reload trang. Quân Phong Tốc độ thực thi cực nhanh trên mọi trình duyệt điện thoại di động; kiểm soát tối đa DOM và luồng offline.
3 Frontend
CSS Print Media (@media print)
 Định dạng và thiết kế trang in Standee QR để bàn (khổ A5/A6), tự động ẩn thanh điều hướng, căn chuẩn khung in. Quân Cho phép in trực tiếp từ trình duyệt ra máy in nhiệt hoặc file PDF mà không vỡ hạt hay lệch trang.
4 Frontend
Chart.js
 Trực quan hóa biểu đồ doanh thu theo ngày/tháng, số lượng đơn hàng, top món ăn bán chạy trên Dashboard Admin. Phong Nhật Thư viện Canvas nhẹ, hiệu năng hiển thị biểu đồ cao, hỗ trợ tương tác và hoạt ảnh sinh động.
5 Backend
Node.js (Runtime)
 Môi trường chạy mã máy chủ JavaScript, xử lý tác vụ bất đồng bộ I/O non-blocking tốc độ cao. Nhật Minh Đồng nhất ngôn ngữ JS xuyên suốt Frontend và Backend; xử lý mượt mà hàng trăm kết nối đồng thời.
6 Backend
Express.js (Framework)
 Xây dựng RESTful API theo cấu trúc Modular Monolith (Routes → Validation → Controller → Service → Model). Nhật Minh Định tuyến rõ ràng, chuẩn phản hồi đồng nhất {ok, data, msg}, dễ dàng tích hợp Middleware kiểm soát bảo mật.
7 Cơ sở dữ liệu
SQLite / MySQL / Postgres
 Lưu trữ dữ liệu quan hệ: người dùng, thực đơn, bàn ăn, phiên bàn, đơn đặt món, chi tiết gọi món và hóa đơn. Phát (DBA) Đảm bảo toàn vẹn dữ liệu (ACID), hỗ trợ Transaction nhiều bước (đặt món, chuyển bàn, thanh toán) chống sai lệch.
8 Cơ sở dữ liệu
DB Browser for SQLite / DBeaver
 Quản trị CSDL trực quan, chạy các script DDL (taoBang.sql, rangBuoc.sql, duLieuMau.sql) và kiểm tra dữ liệu. Phát Dễ dàng rà soát khóa ngoại, chỉ mục (Index) và kiểm tra các ràng buộc CHECK/UNIQUE trước khi tích hợp vào code.
9 Real-time
Socket.io
 Đồng bộ thời gian thực: Khách đặt món ➔ Bếp (KDS) nhận đơn ➔ Thu ngân (POS) cập nhật trạng thái tức thời. Nhật Phong Cơ chế chia Room độc lập (Bàn/Bếp/Thu ngân), tự động kết nối lại (Auto-reconnect) khi rớt mạng Wi-Fi.
10 Bảo mật
bcryptjs
 Mã hóa băm mật khẩu một chiều (one-way hashing kèm muối Salt) cho tài khoản nhân viên và quản lý. Nhật Ngăn ngừa lộ mật khẩu ngay cả khi CSDL bị trích xuất, chống lại các hình thức tấn công Rainbow table.
11 Bảo mật
JSON Web Token (JWT)
 Xác thực người dùng không lưu trạng thái (Stateless), cấp phát Access Token và Refresh Token kèm phân quyền RBAC. Nhật Phân tách nghiêm ngặt quyền hạn giữa Khách hàng, Nhân viên, Thu ngân, Bếp và Quản trị viên.
12 Mã QR
Thuật toán SVG QR thuần Client
 Sinh mã QR SVG vector trực tiếp trên trình duyệt (taoQrClient.js) dựa trên thuật toán Reed-Solomon / ISO 18004. Quân Hoạt động 100% offline không cần internet hay API bên ngoài; tạo mã tức thì < 5ms, in ấn không vỡ hình.
13 Quản lý mã
Git & GitHub
 Quản lý phiên bản mã nguồn phân tán, phân nhánh tính năng (fe-quan-sprint1, fe-quan-sprint2) và duyệt Pull Request. Cả nhóm (Nhật review) Lưu vết lịch sử thay đổi minh bạch, kiểm soát xung đột (Merge Conflict), quy trình GitHub Flow chuẩn mực.
14 Quản trị Agile
GitHub Issues & Milestones
 Quản lý 140 User Stories, gắn nhãn (feature, bug, testing, ai-assisted), chia 4 Milestone theo từng tuần Sprint. Cả nhóm Theo dõi trực quan tiến độ hoàn thành, liên kết trực tiếp giữa tác vụ yêu cầu và commit/PR minh chứng.
15 Kiểm thử
Postman & Node.js Assert
 Kiểm thử tự động và thủ công các endpoint REST API (kiemThu/api/kiemThuTrucTiep.js), kiểm tra mã HTTP phản hồi. Minh Quân Phát hiện sớm lỗi xác thực dữ liệu đầu vào (Validation 400), mã lỗi nghiệp vụ (401, 403, 404, 409).
16 Trợ lý AI
DeepMind Antigravity / AI Assistant
 Hỗ trợ giải quyết xung đột Git, tối ưu thuật toán QR offline, thiết kế bộ lọc thực đơn và giao diện responsive. Quân Minh Tăng tốc độ phát triển; nhóm luôn đọc hiểu, đối chiếu thực tế và kiểm thử mã nguồn trước khi tích hợp.
17 Triển khai
Vercel & Cloud Server / Localhost
 Triển khai tự động Frontend tĩnh lên Vercel và vận hành Backend API Node.js trên máy chủ. Nhật Phong Tích hợp CI/CD tự động build khi gộp PR vào nhánh main, hỗ trợ tên miền tùy chỉnh và chứng chỉ SSL/HTTPS.
18 Tài liệu
Figma & MS Word / Markdown
 Thiết kế Wireframe phác thảo giao diện, biên soạn báo cáo bài tập lớn chuẩn văn phong học thuật. Cả nhóm Quy chuẩn định dạng đồng bộ (Times New Roman, căn lề 3-2-2-2 cm, bảng biểu chuẩn theo mẫu của khoa).
